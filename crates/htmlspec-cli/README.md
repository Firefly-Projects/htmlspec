# htmlspec-cli

The `htmlspec` command: create, validate, format, and archive HTMLSpec documents, the
specifications, changes, and runbooks a project keeps as plain HTML files that a browser opens
and an agent edits.

```sh
cargo install --locked htmlspec-cli
```

`--locked` builds with the dependency versions the release was tested with. The binary is named
`htmlspec`, and `htmlspec --version` names the version and the commit it was built from.

The other ways to install it, the documents it reads and writes, and how a project uses it are
in the project's README, at https://github.com/Firefly-Projects/htmlspec.
