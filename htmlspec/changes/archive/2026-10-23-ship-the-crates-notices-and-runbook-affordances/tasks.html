  • 3.2 Add htmlspec format --upgrade-assets task-3-2

    As the design's decision 8 states. It is the third exception to deterministic-formatting's "Formatting preserves meaning", made only on request, with --check. It never touches an archived change or a run's record, whether reached directly or through a symbolic link. Its help says plainly that it rewrites references to the store's current assets and never downloads anything. Tests:

    • a document on an older stylesheet moves onto the current one;
    • assets a document does not load stay unreferenced;
    • without the flag, a reference to an older stored revision is left as written;
    • an archived document and a run's record are untouched, including through a link;
    • the run is idempotent;
    • a store missing the current bytes is filled from the binary with no network access.

    Record the flag in 1.1.json.

    Two kinds of reference stay as written rather than every one being rewritten: one naming a file the binary embeds no revision of, and one whose stored bytes disagree with its address, which asset/mismatch reports. Decision 8's note records why. The rewrite is a new function, htmlspec_format::upgrade, beside rewrite, so the published ReferenceChange enum gains no variant.
