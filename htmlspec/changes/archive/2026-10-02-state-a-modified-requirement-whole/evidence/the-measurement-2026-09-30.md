### The sync rule in OpenSpec 1.13.1, which is what `openspec` runs

**This differs from the copy above.** The installed 1.13.1 has moved.
`lib/openspec/dist/core/templates/workflows/sync-specs.js`, lines 239-244:

```
**Key Principle: Intelligent Merging**

Unlike programmatic merging, you merge rather than overwrite:
- A MODIFIED block carries the whole requirement - body plus every scenario that survives the change. `openspec validate` and `openspec archive` both reject one that drops a scenario the main spec still has.
- Keep anything the delta does not mention, in the main spec's existing order
- Use your judgment to merge changes sensibly
```

One line of the older wording survives in its step list, lines 108-114:

```
      **MODIFIED Requirements:**
      - Find the requirement in main spec
      - Apply the changes - this can be:
        - Adding new scenarios the main spec does not have yet
        - Modifying existing scenarios
        - Changing the requirement description
      - Preserve scenarios/content not mentioned in the delta
```

The check behind the principle is in two places:

- `dist/core/validation/validator.js` lines 648-650: `MODIFIED "…" omits scenario(s) the current spec
  still has: … Copy them into the MODIFIED block (a MODIFIED requirement replaces the whole block, so
  archive refuses to drop them).`
- `dist/core/specs-apply.js` line 388: `… current spec contains scenario(s) not present in the modified
  block: … Refresh the change spec before archiving to avoid dropping scenarios.`

Both call `findMissingCurrentScenarios` (`dist/core/parsers/requirement-blocks.js` lines 392-414).
That function compares scenario names only, so a paragraph left out is not refused. At 1.13.1, then,
the principle and both commands require every scenario, and the surviving "Preserve scenarios/content
not mentioned" line can no longer apply to a scenario in a delta that validates.

## 3. The count across the archive

### Method

For each archived change and each capability its deltas modify, the script in appendix A takes:

- **the merge commit `M`.** This is the commit that added the archive directory, when that commit also
  edits `openspec/specs/<cap>/spec.md`. Otherwise it is the last commit before it that did.
- **before**: the accepted specification at `M^`, which is what the delta modified.
- **the delta**: as committed at the archive's landing commit.
- **after**: the accepted specification at `M`, which is what the merge left.

For a renamed requirement, "before" is looked up under the `FROM:` heading. A requirement's content is
its statement paragraphs, separated by blank lines and whitespace-normalized, and its scenarios, by name
with whitespace-normalized text.

A block **restates the requirement whole** when every scenario name "before" held is in the delta, and
no "before" paragraph that the delta lacks survives in "after". A "before" paragraph that the delta lacks
and "after" also lacks was rewritten or deleted by the change, which a whole restatement is free to do.

For three changes, the archive commit does not edit the modified capability's specification, so the
merge is an earlier commit:

| Change | Archive commit | Merge commit |
| --- | --- | --- |
| `2026-08-21-check-release-hygiene` | `afc2bdc`, which edits no specification | `41310f8` "Check release hygiene in the project's own suite" |
| `2026-08-21-distinguish-command-names-from-skill-names` | `3b1ca92`, which edits no specification | `c864727` "Stop a command file from declaring its skill's name (#6)" |
| `2026-08-24-pass-the-description-through` | `bfc3835`, which edits only `workflow-reporting` | `4f2f3e7` "Pass a contributor's arguments through the invocation (#11)" |

`bfc3835` and `17afc05` each archive two changes. In both, only one of the two carries MODIFIED blocks.

## Appendix A: `count.py`

```python
#!/usr/bin/env python3
"""Counts, for every MODIFIED requirement block in every archived delta, whether it restates
the requirement the accepted specification held when the change's contract was merged.

For each archived change and each capability its deltas modify:
  M      = the merge commit: the commit that added the archive directory, when that commit also
           edited openspec/specs/<cap>/spec.md; otherwise the last commit before it that did.
  before = openspec/specs/<cap>/spec.md at M^ (what the delta modified)
  delta  = the delta file as committed at the archive landing commit
  after  = openspec/specs/<cap>/spec.md at M (what the merge left)

A requirement's content is its statement paragraphs (blank-line separated, whitespace
normalized) and its scenarios (by name, text whitespace normalized). Read only.

Usage: count.py <repository>
"""

import json
import re
import subprocess
import sys
from pathlib import Path

REPO = Path(sys.argv[1])
SECTION = re.compile(r"^## (ADDED|MODIFIED|REMOVED|RENAMED) Requirements\s*$")
REQUIREMENT = re.compile(r"^### Requirement: (.+?)\s*$")
SCENARIO = re.compile(r"^#### Scenario: (.+?)\s*$")
PAIR = re.compile(r"^\s*-\s*(FROM|TO):\s*`?(?:### Requirement:\s*)?(.+?)`?\s*$")


def git(*args):
    r = subprocess.run(["git", "-C", str(REPO), *args], capture_output=True, text=True)
    return r.returncode, r.stdout


def norm(t):
    return re.sub(r"\s+", " ", t).strip()


def paragraphs(lines):
    out, cur = [], []
    for line in lines + [""]:
        if line.strip():
            cur.append(line)
        elif cur:
            out.append(norm("\n".join(cur)))
            cur = []
    return out


def parse(text):
    """{section: {heading: {"paras": [...], "scenarios": {name: text}}}}, plus rename pairs."""
    out, pairs, pending = {}, [], None
    section, cur, sc = None, None, None
    for line in text.splitlines():
        m = SECTION.match(line)
        if m:
            section, cur, sc = m.group(1), None, None
            continue
        if line.startswith("## "):
            section = "ACCEPTED" if line.strip() == "## Requirements" else None
            cur, sc = None, None
            continue
        if section == "RENAMED":
            p = PAIR.match(line)
            if p:
                if p.group(1) == "FROM":
                    pending = p.group(2).strip()
                else:
                    pairs.append((pending, p.group(2).strip()))
            continue
        r = REQUIREMENT.match(line)
        if r and section:
            cur = {"lines": [], "scenarios": {}, "order": []}
            out.setdefault(section, {})[r.group(1).strip()] = cur
            sc = None
            continue
        s = SCENARIO.match(line)
        if s and cur is not None:
            sc = s.group(1).strip()
            cur["scenarios"][sc] = []
            cur["order"].append(sc)
            continue
        if cur is None:
            continue
        (cur["scenarios"][sc] if sc else cur["lines"]).append(line)
    for blocks in out.values():
        for b in blocks.values():
            b["paras"] = paragraphs(b.pop("lines"))
            b["scenarios"] = {k: norm("\n".join(v)) for k, v in b["scenarios"].items()}
    return out, pairs


def landing(change):
    _, out = git("log", "--diff-filter=A", "--format=%H", "--", f"openspec/changes/archive/{change}")
    return out.split()[-1]


def merge_commit(landing_commit, cap):
    path = f"openspec/specs/{cap}/spec.md"
    _, touched = git("show", "--format=", "--name-only", landing_commit)
    if path in touched.split():
        return landing_commit
    _, out = git("log", "-1", "--format=%H", f"{landing_commit}^", "--", path)
    return out.strip()


rows = []
for change_dir in sorted((REPO / "openspec/changes/archive").iterdir()):
    change = change_dir.name
    L = landing(change)
    for delta_path in sorted(change_dir.glob("specs/*/spec.md")):
        cap = delta_path.parent.name
        rel = str(delta_path.relative_to(REPO))
        _, delta_text = git("show", f"{L}:{rel}")
        delta, pairs = parse(delta_text)
        modified = delta.get("MODIFIED", {})
        if not modified:
            continue
        M = merge_commit(L, cap)
        code_b, before_text = git("show", f"{M}^:openspec/specs/{cap}/spec.md")
        _, after_text = git("show", f"{M}:openspec/specs/{cap}/spec.md")
        before = parse(before_text)[0].get("ACCEPTED", {}) if code_b == 0 else {}
        after = parse(after_text)[0].get("ACCEPTED", {})
        renamed_from = {to: frm for frm, to in pairs}
        for heading, d in modified.items():
            b = before.get(heading) or before.get(renamed_from.get(heading, ""))
            a = after.get(heading)
            row = {"change": change, "capability": cap, "heading": heading,
                   "landing": L[:7], "merge": M[:7],
                   "renamed_from": renamed_from.get(heading)}
            if b is None:
                row["class"] = "no accepted requirement at the time"
                rows.append(row)
                continue
            omitted_sc = [s for s in b["scenarios"] if s not in d["scenarios"]]
            omitted_pa = [p for p in b["paras"] if p not in d["paras"]]
            row["before_scenarios"] = list(b["scenarios"])
            row["delta_scenarios"] = list(d["scenarios"])
            row["after_scenarios"] = list(a["scenarios"]) if a else None
            row["omitted_scenarios_kept"] = [s for s in omitted_sc if a and s in a["scenarios"]]
            row["omitted_scenarios_dropped"] = [s for s in omitted_sc
                                                if not (a and s in a["scenarios"])]
            row["paragraphs_before"] = len(b["paras"])
            row["paragraphs_not_restated_verbatim"] = len(omitted_pa)
            row["paragraphs_not_restated_but_kept"] = [p[:90] for p in omitted_pa
                                                       if a and p in a["paras"]]
            row["after_equals_delta"] = bool(a) and a["paras"] == d["paras"] and \
                a["scenarios"] == d["scenarios"]
            row["after_equals_delta_ignoring_order"] = bool(a) and \
                sorted(a["paras"]) == sorted(d["paras"]) and a["scenarios"] == d["scenarios"]
            partial = row["omitted_scenarios_kept"] or row["paragraphs_not_restated_but_kept"]
            if omitted_sc or partial:
                row["class"] = "omits accepted content"
            else:
                row["class"] = "whole"
            rows.append(row)

json.dump(rows, sys.stdout, indent=1, ensure_ascii=False)
```
