Read a development shell built by import from a derivation: tasks

The work that lets the toolchain check read a development shell that imports from a derivation while building and downloading nothing, makes its refusal quote Nix's error, tests both against real Nix, corrects the two documents that described the old flag, and ships it as 1.3.2. One pull request: the release opens first, the tests come before the code they hold, and archival closes it.
