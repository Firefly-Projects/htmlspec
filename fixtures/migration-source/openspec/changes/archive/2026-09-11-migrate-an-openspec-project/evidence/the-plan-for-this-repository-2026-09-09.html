The migration plan for html-spec's own OpenSpec project: one task unit for each of the 201 entities the survey found, carrying its source path, its destination, its disposition, and — where one is owed — the reason it was folded or dropped. 236 identifier derivations are recorded against the source document that stated each heading. This is the artifact of the first four migration stages, and the only check on whether the reading behind it happened is a person reading these lines.
