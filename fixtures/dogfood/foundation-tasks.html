The html-spec foundation change: tasks

The work that delivered the foundation change, as its own document. Hand-authored with no tooling. The contract this work established is in the specification beside it, and the separation is the point: a completed task is history, while the obligation it satisfied survives.

Tasks

Each task names the obligation it served in prose rather than with data-refs. A reference resolves within one document, so a task cannot address a requirement that lives in the specification beside it — see the note below, which records that as a finding rather than hiding it.

  • Enumerate every recovered parse error under the pinned parser

    Served the deterministic-parse requirement. The spike found that a conforming document produces no recovery at all, so the permitted-recovery allowlist is empty.

  • Draft the vocabulary as JSON Schema

    Served the machine-readable-contract requirement.

  • Hand-author three documents against the draft contract

    Held down the risk that a closed seven-unit vocabulary proves incomplete. Sequenced before the parser and the validator, because revising the contract here costs a schema edit and revising it later costs a migration.

  • Validate Mermaid diagram source completely

    Dropped for this change because no Rust implementation of the Mermaid grammar exists, and a headless browser check is out of scope.

What the split made awkward

Splitting this change into four documents cost the machine-readable link between a task and the requirement it serves. Before the split, every task above carried data-refs naming a requirement in the same file, and the validator resolved it. A reference is scoped to one document, so those attributes now name identifiers no unit in this document declares, and keeping them would report four unresolved references.

The prose notes above carry the same information for a reader and none of it for a tool. That is a real loss and it is recorded here rather than in a commit message, because this document is one of the project's shipped examples of its own vocabulary and an example that hid the awkward part would be a worse example.
