Conclusions

The renderer draws into a sibling

Mermaid is configured to render into an element beside the source rather than over it.

Mermaid's default behavior replaces the source block, which destroys the source the moment anyone saves a rendered DOM. A saved page is how these artifacts get shared, so the default is unusable and a test asserts the sibling behavior.

Mermaid source cannot be fully validated in Rust

No Rust implementation of the Mermaid grammar exists, so validation checks that a block is non-empty and opens with a recognized diagram keyword. The diagram in the pipeline figure is checked only that far.

The visible-source fallback limits the damage: a broken diagram still shows its caption and its source, so the document stays reviewable.
