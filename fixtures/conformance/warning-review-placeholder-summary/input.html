Requirements

A placeholder summary is reported req-a-placeholder-summary-is-reported

Validation SHALL report a document whose whole summary is a paragraph a template writes as a placeholder.

The units were replaced and the masthead was not

Given
A document created from a template, whose every unit identifier is the author's own.
When
The masthead paragraph is left exactly as the template wrote it.
Then
The summary is reported, because no unit identifier remains for the identifier check to find.
